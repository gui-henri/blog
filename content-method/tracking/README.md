# Tracking

The honesty ledger: hours studied vs. artifacts produced.

The maxim's rule — each hour of study should ideally leave an artifact. This log makes it
measurable. It is allowed to be rough; it is not allowed to be empty.

## How to use

- Open the log for the current month.
- After each session, add one row: what was studied, what survived, how long it took.
- If an hour produced nothing, write the row anyway with `artifact: none` and a note why.
  A written miss is still a data point.
- Weekly review: read the week back. What pattern appears?

## Fields

| Field | Meaning |
| --- | --- |
| date | YYYY-MM-DD |
| hours | Time spent, in hours |
| topic | What was studied or worked on |
| artifact | What survived the session (note/essay/code/post) — or `none` |
| channel | Where it was distributed, if anywhere |
