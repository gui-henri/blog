# Short video (30–60 s)

Source essay: <link>

## One idea only

What is the single thing this short says? Write it as one sentence.

## Script

0–5 s — Hook: state the idea in a question or a contradiction.
5–35 s — Example: show the thing happening (screen capture, code, sketch).
35–55 s — The fix or the rule, stated plainly.
55–60 s — CTA: "Full write-up linked below" / "Follow for more of this."

## Production

- Vertical 9:16. Captions on always.
- One visual per sentence.
- 30–60 seconds. If it can't be said in 60 s, it's a carousel, not a short.
