Go is one of my favorite languages to learn programming. It's basically C, but some of the pains of working with it. And although not perfect, it's simplicity can be used to teach fundamentals of programming in a more modern setting. Rust, for example, complicates the use of many data structures we are used to see in university (specially the ones who make heavy use of pointers) because of it's borrow checker. C itself is easy to teach, but only when some aspects of the language are simplified (this usually comes from utility functions and platforms that compile the code for you). Go does have it's problems, but in terms of usability for newcomers, it's simplicity and very proximity to C syntax make it easy to teach data structures, as well as the rationale behind their use.

Python (or any other dynamic language) also have an disadvantage in comparison to Go, since it abstracts many constructs away from the students. Go also has a lot of utilities built-in, but unlike Python, the reason why they exist is more clear. One great example is how everything is a pointer in Python, but the language abstracts this fact. Students may find the edge cases of dealing with pointers and not know why they happen, and because Python doesn't have traditional variables, teaching the difference between one and another becomes much more theorical than practical. Teaching this in Go, on the other hand, is easier because the language has both.
